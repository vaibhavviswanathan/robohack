## Quick install 

```bash
uv venv --python 3.10
. ./venv/bin/activate
uv pip install -r requirements.txt
```

if you're running on mac, you can use:
```bash
brew install python@3.10
```
and if you need uv:
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh 
```
